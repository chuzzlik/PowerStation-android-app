# PowerStation Android App

**Версия приложения: 1.0.0**  
**Совместимая версия прошивки станции: 2.7.0**  
**Версия BLE API: 7**

Мобильное приложение для мониторинга и настройки зарядной станции PowerStation через Bluetooth Low Energy.

## Возможности

- автоматическое подключение к привязанной станции;
- отображение текущего состояния станции;
- отображение уровня заряда, мощности, напряжения и тока;
- расчёт оставшегося времени зарядки или разрядки;
- отображение температуры силового модуля и выходящего воздуха;
- отображение текущей мощности вентилятора;
- настройка параметров аккумулятора, экранов, расчёта времени и охлаждения;
- управление обучением фактической ёмкости аккумулятора;
- автоматическое определение потери соединения и повторное подключение;
- перелистывание основных разделов приложения горизонтальными свайпами.

## Совместимость

| Компонент | Версия |
|---|---:|
| Android-приложение | 1.0.0 |

## Разделы приложения

### Станция

Отображает основные текущие показатели:

- режим работы станции;
- процент заряда;
- текущий запас энергии;
- обученную ёмкость аккумулятора;
- мощность;
- напряжение;
- ток;
- расчётное время;
- температуры;
- состояние вентилятора.

### Параметры

Позволяет изменять настройки станции:

- тайм-ауты экранов;
- порог низкого заряда;
- ограничение мощности;
- нижний порог напряжения;
- параметры определения полного заряда;
- параметры расчёта времени;
- обученную ёмкость;
- параметры управления вентилятором;
- параметры температурного регулирования.

В этом же разделе находятся управление и состояние обучения ёмкости аккумулятора.

### Приложение

Содержит информацию о подключённой станции, версии прошивки, Bluetooth-адресе и действия для отключения или удаления привязки.

## Технологии

- Kotlin;
- Jetpack Compose;
- Android Bluetooth Low Energy;
- JSON-протокол обмена данными;
- Material 3.

## Репозитории

- приложение: `PowerStation-android-app`;
- прошивка станции: `PowerStation-stm32-firmware`.

## Версионирование

Версии приложения используют формат:

`MAJOR.MINOR.PATCH`

- `MAJOR` — несовместимые изменения приложения или протокола;
- `MINOR` — новые функции с сохранением совместимости;
- `PATCH` — исправления ошибок и небольшие изменения интерфейса.
